# Sitio web de Artis Global · somosartis.com

Sitio estático publicado con GitHub Pages desde la carpeta `docs/` (rama `main`). El dominio se define en
`docs/CNAME` (`www.somosartis.com`); los registros DNS viven en SiteGround.

- `docs/index.html`, `docs/index.css`, `docs/index.js`: página principal.
- `docs/brandbook.html`, `docs/privacy.html`: manual de marca y política de privacidad.
- `docs/guia/index.html`: `somosartis.com/guia` redirige a GUÍA, que corre aislada en `https://guia.somosartis.com`.

Copia con historial del repositorio original `matisisconsultancy/Artis-Global` (6 oct 2026).

Comprobación: `https://www.somosartis.com/guia/` debe llevar a `https://guia.somosartis.com/`.
